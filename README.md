# EVLAMP Music (Android / C#)

Исходный проект-заготовка для .NET MAUI Android. Интерфейс: чёрный + фиолетовый неон.
Есть выбор аудиофайлов системным файловым окном, очередь, play/pause, next/previous,
shuffle и repeat. Для сборки используется GitHub Actions, поэтому собирать можно с телефона.

## Важно
Это исходный проект, не готовый/проверенный APK. Сборка зависит от актуальных версий .NET MAUI
и Android SDK на runner. Если workflow завершится ошибкой, откройте лог и исправьте конкретную
ошибку. В первой версии фоновое воспроизведение реализовано через Android foreground service;
поведение уведомления и ограничения батареи зависят от версии Android/прошивки.

## Сборка с телефона
1. Создайте репозиторий GitHub `evlamp-music`.
2. Загрузите в репозиторий все файлы и папки из архива, включая `.github`.
3. Откройте Actions → Build EVLAMP Music APK → Run workflow.
4. После завершения откройте workflow run, внизу Artifacts скачайте `EVLAMP-Music-APK`.
5. Распакуйте артефакт и установите APK. При необходимости разрешите установку приложений из браузера/файлового менеджера.

## Среда
.NET 9 MAUI, Android. В проекте нет рекламы, сетевого аудио или подписок.
